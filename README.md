# 机器人探索站 · 识图、档案与 G1 动作探索

开发或接手前先读 [展厅项目上下文](docs/exhibition-context.md)：集中记录竖屏设备参数、游客操作要求、安卓触屏与性能注意事项、布局回归和发布方式。G1 具体实现见 [G1 README](demos/g1/README.md)。

适合展厅横屏、竖屏和手机浏览的机器人互动应用，采用浅绿「机器人档案馆」界面。首页整合识图挑战、G1 专题和 150 台机器人档案三个入口。纯前端，无外部 CDN；修改 G1 三维源码后需要重新构建其本地包。2026-11-16 档案新版发布记录见 [发布与回档说明](docs/releases/2026-11-16-robot-archive.md)。

## 怎么玩

- 首页直接点击“开始挑战”即可开局。昵称选填，留空使用“小小观察员”；也可填写 1—12 个字或选择快捷昵称。
- 首页可进入 G1 专题，或在新页面打开 `demos/g1/` 三维互动，包含自由观察、寻找自由度及 13 个手动摆姿训练动作。G1 顶栏“游戏首页”返回原入口，详细操作见 `demos/g1/README.md`。首页使用约 325 KB 静态模型示意图，进入互动后才加载三维包与模型；档案改版不修改题库、评分或 G1 三维逻辑。
- 机器人档案馆支持展品编号、型号、公司、国家或年份搜索，按年份筛选，每页展示 12 台。稳定资料 ID 与展品编号分别保留，例如 G1 为资料 ID 143 / 展品编号 137。
- 点击档案卡片查看完整照片、基本信息、简介、技术路线、应用场景和优势与边界。返回列表保留搜索、年份与页码；列表和详情均可直接开始挑战。
- 149 台普通机型使用原照新版详情，G1 使用独立专题；分为概览、技术与应用、完整资料和二维码。150 张原照均完整显示，四段原文逐字保留；缺项显示“暂未收录”。原档案 `archive.html` 与原有公开二维码地址继续可用。首页与档案由 `js/archive/`、`css/archive/`、`data/archive-records.js` 和 `assets/archive/` 提供；G1 专题使用 Shadow DOM 隔离样式，原识图流程继续使用 `js/exhibition-app.js`。
- 每局随机抽取 10 道识图题，每题 4 选 1；照片完整显示。
- 选择后显示正确答案，手动点下一题；照片加载、反馈和退出确认时间不计入答题用时。
- 结束后展示昵称、答对数、正确率、用时、超越人数、累计参与人次。
- **错题回放为一页总览**：最多 10 道错题，在 1080p/4K 横屏上同时显示照片、当时所选和正确答案。错题少时自动放大，手机上为同一页面纵向浏览。
- 刷新后仍可查看最近完成一局的错题。下一位挑战时可直接开始或另填昵称。

## 统计口径

初始参与基数为 **1,000 人次**。原游戏没有历史成绩，因此“超越人数”包含 1,000 份固定模拟成绩，页面明确标注。按答对题数优先、用时次之比较，完全相同不算超越。

每完成一局累计 1 人次，未完成、刷新和回放不重复计数。重复游玩算多次，不能据此统计独立访客。记录保存在当前设备的浏览器中，不进行跨设备汇总；清除站点数据或更换浏览器/访问地址会产生独立记录。

历史成绩只含匿名分数、用时与随机局 ID；昵称和详细题目只保存最近一局。存储键为 `robot-game-exhibition-v1`。无法保存时页面会提示，本局仍可回放。

## 使用与验证

正式入口：<https://bwys-34.github.io/robot-game/>。

完整应用需要 HTTP 服务，G1 模型不能通过双击 HTML 的 `file://` 地址加载。从项目根目录执行 `node tools/serve.cjs`，打开 `http://127.0.0.1:8765/`。展厅长期运行建议使用固定浏览器和固定地址。右上角支持全屏；自定义中文昵称使用系统输入法/屏幕键盘，也可点选快捷昵称。

```sh
node --test test/*.test.js
```

87 项测试覆盖原题库、随机抽题、昵称、计数、排名、存档恢复和错题快照，以及档案搜索、排序、分页边界、150 条详情与照片编号关联，另含 G1 关节、发现状态、阻尼、碰撞代理、十二个训练目标和评分规则，以及绘制像素预算和重复计算回归。视觉检查覆盖横屏及 720×1280、1080×1920、2160×3840 竖屏；错题总览另检查 1、4、6、10 道和满分状态。

兼容展厅 Android Chrome 88：启动不依赖 `Object.hasOwn`，视口高度提供 `vh` 回退，不支持原生 `dialog` 时使用可触摸、可键盘操作的退出确认层。答题中通过页头或浏览器返回切换页面时，也会先确认退出。

浅绿首页以 G1 模型示意和档案馆入口为主，随后是识图挑战、G1 互动及更多机器人。首页与详情按内容滚动；列表桌面四列、中等宽度三列、窄屏两列。手机详情先展示型号和完整原照，再阅读章节。答题页与错题总览保留原流程，并统一周边颜色。

`node test/archive-site.cjs` 在 `/robot-game/` 项目路径下检查全部 150 档案、五类页面 × 六视口、原照/原文/稳定地址、筛选及分页返回、G1 静态视图与入口、完整十题/成绩/错题/存档及缺少原生 dialog 的照片弹窗。可用 `SITE_ROOT` 指向暂存快照，或用 `SITE_URL` 指向正式站点；Playwright Core 和浏览器支持 `PLAYWRIGHT_CORE_PATH` / `BROWSER_PATH`。截图与 JSON 输出到 `work/archive-release/`。

`test/home-integration.cjs` 与 `test/browser-compat.cjs` 保留旧黄黑首页和 iframe 档案的历史验证脚本；当前新版使用上述 `test/archive-site.cjs`。现代 Edge 中的兼容场景模拟不等同实体 Chrome 88 验收，现场设备仍需复核。

`index.html` 为案例三展厅入口，`index-original.html` 保留改版前的手机版。沿用 `data/` 和 `photos/`，无需重复下载素材。实体触屏的系统缩放、屏幕键盘和安装高度需在展厅确认。
