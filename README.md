# 机器人探索站 · 档案与识图挑战

适合 65 英寸展厅横屏与竖屏的机器人互动应用，采用黄黑「机器人研究所」界面。150 台机器人的档案与识图挑战在同一页面内切换，共用现有机型和照片，纯前端，无构建步骤和外部 CDN。

## 怎么玩

- 首页直接点击“开始挑战”即可开局。昵称选填，留空使用“小小观察员”；也可填写 1—12 个字或选择快捷昵称。
- 机器人档案馆已整合在应用内：支持编号、型号、公司、国家或年份搜索，按年份筛选，保留原档案馆浅绿界面，每页展示 12 台。
- 点击档案卡片查看完整照片、基本信息、简介、技术路线、应用场景和优势与边界。返回列表保留搜索、年份与页码；列表和详情均可直接开始挑战。
- 原档案页面、样式及完整内容本地保存于 `archive.html` 和 `js/vendor/original-archive.js`，以同源内嵌页面隔离游戏样式，来源为原有[公开档案](https://bwys-34.github.io/robot-QR-code/robots.html)，以稳定编号关联游戏照片。原始资料缺少的字段显示“暂未收录”，不补写推测内容。
- 每局随机抽取 10 道识图题，每题 4 选 1；照片完整显示。
- 选择后显示正确答案，手动点下一题；照片加载、反馈和退出确认时间不计入答题用时。
- 结束后展示昵称、答对数、正确率、用时、超越人数、累计参与人次。
- **错题回放为一页总览**：最多 10 道错题，在 1080p/4K 横屏上同时显示照片、当时所选和正确答案。错题少时自动放大，手机上为同一页面纵向浏览。
- 刷新后仍可查看最近完成一局的错题。下一位挑战时可直接开始或另填昵称。

## 统计口径

初始参与基数为 **1,000 人次**。原游戏没有历史成绩，因此“超越人数”包含 1,000 份固定模拟成绩，页面明确标注。按答对题数优先、用时次之比较，完全相同不算超越。

每完成一局累计 1 人次，未完成、刷新和回放不重复计数。重复游玩算多次，不能据此统计独立访客。记录保存在当前设备的浏览器中，不进行跨设备汇总；清除站点数据或更换浏览器/访问地址会产生独立记录。

历史成绩只含匿名分数、用时与随机局 ID；昵称和详细题目只保存最近一局。存储键为 `robot-game-exhibition-v1`。无法保存时页面会提示，本局仍可回放。

## 使用与验证

正式入口：<https://bwys-34.github.io/robot-game/>。

本地可直接打开 `index.html`。展厅长期运行建议使用固定浏览器和固定地址的本机 HTTP 服务。右上角支持全屏；自定义中文昵称使用系统输入法/屏幕键盘，也可点选快捷昵称。

```sh
node --test test/*.test.js
```

23 项测试覆盖原题库、随机抽题、昵称、计数、排名、存档恢复和错题快照，以及档案搜索、排序、分页边界、150 条详情与照片编号关联。视觉检查覆盖 1920×1080、3840×2160、1366×768 横屏及 720×1280、1080×1920、2160×3840 竖屏；错题总览另检查 1、4、6、10 道和满分状态。

兼容展厅 Android Chrome 88：启动不依赖 `Object.hasOwn`，视口高度提供 `vh` 回退，不支持原生 `dialog` 时使用可触摸、可键盘操作的退出确认层。答题中通过页头或浏览器返回切换页面时，也会先确认退出。

横屏首页左侧展示标题与机器人照片，右侧突出开始按钮和档案入口。宽度超过 600 CSS 像素的竖屏依次展示标题、操作区、照片；档案恢复原有三列列表（窄屏为两列），详情保留原图、完整章节和二维码。答题页为上图下选项，错题页为两列总览。大屏首页保持一屏可用；档案保持原有整页滚动方式。

可选浏览器回归检查：安装 Playwright Core 后运行 `node test/browser-compat.cjs`，通过 `BROWSER_PATH` 指定本机 Chrome/Edge 可执行文件。也可通过 `PLAYWRIGHT_CORE_PATH` 指定现有 Playwright Core 模块。检查现代浏览器，以及移除 `Object.hasOwn`、`crypto.randomUUID`、原生弹窗方法并丢弃 `svh` 声明的兼容场景；覆盖档案搜索与返回、可选昵称、导航退出确认、横竖屏布局、完整答题、错题回放和刷新恢复。这是在当前浏览器中模拟相关限制，实体 Chrome 88 设备仍需现场复核。

`index.html` 为案例三展厅入口，`index-original.html` 保留改版前的手机版。沿用 `data/` 和 `photos/`，无需重复下载素材。实体触屏的系统缩放、屏幕键盘和安装高度需在展厅确认。

```bash
python tools/compress_photos.py "<源照片目录>" photos data/photos.js
```
