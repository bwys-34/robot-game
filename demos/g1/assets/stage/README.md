# 台阶舞台（2026-11-16，本地预览）

原创低面数展厅道具，通过本机 Blender 5.2.3 LTS / Blender MCP 制作，使用已安装 ND 2.2.1 的 `new_modifier` 工具创建倒角修饰器。制作脚本 `work/g1-stage/build_stage.py`，编辑工程 `work/g1-stage/stage.blend`。

- `stage.glb`：约 31 KB，四组材质 / 四个网格，unlit 材质，无贴图、骨骼、实时阴影。
- 舞台宽 4.7m、深 3.45m、高 0.32m；前方两级踏步各深 0.36m，总深度 4.17m。
- 原点位于舞台底面中心。网页整体平移到 `STAGE_CONFIG.center`；脚底、目标圈和影子使用同一高度。
- 模型失败时立即保留同尺寸程序几何，不依赖额外网络服务。

台阶作为不可直接步行跨越的障碍。当前互动为用户指定的「锁定站立 → 确认人工搬运 → 放稳 → 恢复控制」网页模拟，不是实物搬运或自主上台阶能力说明。
