# G1 教学手柄按键调整报告

日期：2026-11-16
状态：方案报告，尚未修改交互代码、构建或发布。

## 1. 调整目标与依据

参考用户提供的 G1 真机手柄照片，让游客形成三组明确的操作记忆：**START 管运动状态与停止表演，SELECT 管接待互动，RB 管可编排舞蹈**。保留现有驾驶、吊挂、调试、考核玩法。

照片可辨认出 SELECT、START 独立按键，以及 SELECT + A 握手、SELECT + Y 高举挥手、SELECT + X 双手打 X、双击 START 踏步 / 站立；下方备注还注明舞蹈中可双击 START 中断。照片作为本次布局参考，不据此推断所有 G1 固件的操作或浏览器输入通道。

当前网页已实现 SELECT + A 握手、SELECT + Y 挥手、SELECT + X 转身挥手。START 单击延迟约 330ms 后切换站立 / 行走，双击进入持续踏步，**缺少明确的舞蹈取消指令**。因此主要改动应集中于 START 的上下文判断、取消动画、说明同步和安卓替代入口。

## 2. 推荐的按键布局

界面继续使用游客实际使用的飞智手柄命名。小图例注明：LB 对应真机 L1，LT 对应 L2，RB 对应 R1，RT 对应 R2；电脑手柄菜单键标为 START（≡），视图键标为 SELECT。图标与物理键能否对应，仍以各设备实测映射为准。

### START：开始、站立、踏步、结束表演

| 所处状态 | 操作 | 建议行为 |
| --- | --- | --- |
| 尚未开始 / 已暂停 | 单击 START | 开始 / 继续体验；保留 A 启动入口。本次启动按键不再触发其他动作，松键松杆后接管。 |
| 正常行走 / 锁定站立 | 单击 START | 行走与锁定站立互切；由行走切站立时先减速停稳。 |
| 正常行走 / 锁定站立 | 双击 START | 原地踏步与锁定站立互切，体现照片上的“踏步 / 站立”。 |
| 动作表演模式，当前没有动作播放 | 单击 / 双击 START | 单击回到锁定站立；双击进入踏步，与播放中的结束语义分开。 |
| 正在播放舞蹈或接待动作 | 单击 START | 不切换模式、不暂停；提示“再按一次 START，结束表演”。 |
| 正在播放舞蹈或接待动作 | **双击 START** | **取消当前动作，平滑收回到站姿，进入锁定站立；不会进入踏步。** |
| 正在执行跳跃 / 后空翻 | 双击 START | 接收结束请求，不再接续动作；当前腾空段完成落地缓冲后站稳，不能半空瞬间复位。 |
| 吊挂调试中正在预览动作 | 双击 START | 结束预览，平滑恢复吊挂基准姿态，仍留在调试，不能解挂或切行走。 |
| 阻尼、零力矩、倒地或挂接 / 解挂过渡 | 单击 / 双击 START | 不绕过现有恢复与吊机流程；显示当前需要的操作，不自动起身或脱离吊带。 |

普通舞蹈建议用约 0.5～0.8 秒收势，实际按关节跨度调整；这是收势时间，识别到双击后应立即显示“正在结束表演”。连续多段节目取消后，清除待播队列，避免下一段又自动播放。

### SELECT：接待互动修饰键

| 操作 | 建议功能 | 与当前实现的关系 |
| --- | --- | --- |
| 按住 SELECT | 在模型外的操作区显示接待组合提示；松开后恢复当前模式说明 | 新增上下文提示，单按不切运动模式 |
| SELECT + A | 伸手握手 | 保留，与照片相符 |
| SELECT + Y | 挥手招呼 | 保留，沿用网页现有动作 |
| SELECT + X | 转身挥手 | 保留现有动作；照片为“双手打 X”，本次不强求一致 |
| SELECT + B | 礼貌鞠躬 | 给现有动作增加快捷入口；组合键不能同时触发 B 暂停 |

接待组合仅在已站稳、未吊挂且具备主动支撑时播放。调试、倒地与挂接过渡中不给这些组合分配隐藏功能。组合键消费必须覆盖按下与释放，尤其不能把 SELECT + A 误当成 A 挂接 / 解挂。

### 其余操作：延续现有学习路径

| 操作 | 电脑标准配置 | 展厅安卓已实测配置 |
| --- | --- | --- |
| 移动与转向 | 左杆移动、右杆转身 | 保留已验证的归一化通道，不能按标准按钮号重绑右杆 |
| 恢复行走 | RT + A | LB + A |
| 阻尼 / 零力矩 | LT + B / Y，LT 按满 2 秒 | LB + B / Y |
| 起身复位 | LT + X，LT 按满 2 秒 | LB + X |
| 进入调试 | 有效吊挂、先切被动模式，再 LT + RT，LT 满 2 秒 | 同样先有效吊挂、切被动模式，再 LB + RB 按住约 0.8 秒 |
| 两档速度 | 双击 LT 低速、双击 LB 高速 | 保留屏幕低速入口、双击 LB 高速 |
| 四个舞蹈快捷键 | RB + A / B / X / Y | RB + A / B / X / Y |
| 挂接、恢复站姿、解挂 | H 圈内沿用 A 的上下文操作 | 沿用 A 的上下文操作 |
| 暂停体验 | 保留单独 B 与页面暂停按钮 | 保留单独 B 与页面暂停按钮 |

RB 四槽沿用浏览器内保存的配置，未自定义时是律动、机械舞、双臂摆舞、加油舞。SELECT 接待组合固定，RB 舞蹈组合可在调试中更换，两者在说明上分栏。

F1 / F3 暂不使用：替代手柄未确认具有对应独立输入，也没有新增按键的必要。

## 3. 安卓屏幕必须单独处理

已记录设备为 Android 11 / Chrome 88，蓝牙飞智手柄。现有实测中未读到 LT / RT、START / SELECT 的响应，安卓归一化配置有意将这些输入留空。**新增功能不能直接套用电脑标准按钮 8 / 9**：在该安卓设备上，这两个原始通道已经用于 LB / RB。

推荐电脑保留实体 START / SELECT；安卓在现有操作台提供以下替代，不要求游客上传文件或重新逐键排查：

- 常驻大号“START · 站立 / 行走”按钮，双击支持同样的踏步或结束表演语义。
- 常驻“SELECT · 接待”入口，点选后展开握手、挥手、转身挥手、鞠躬四张卡，再点卡执行；触屏不要求一手按住修饰键、一手再点动作。
- 表演时将 START 按钮改为明显的“结束表演”，单击即可结束；旁边保留“手柄双击 START”说明，但未读到实体键时明确标注“本屏请点此结束”。
- 已验证的 LB 模式组合、RB 舞蹈组合继续可用。以后实体设备读到 START / SELECT，再接入对应配置，不猜测映射。

## 4. 界面与教学反馈

保留现有模式入口、任务与模型分区，文字不遮挡机器人，不增加页面或面板滚动。按展厅 CSS 1080×1800 / 实体 1080×1920 设计操作区，并兼顾已有横屏条件。

操作说明优先展示三条短句：“START 管站立 / 踏步”“SELECT + 彩色键做接待”“RB + 彩色键播舞蹈”。表演开始后优先展示“正在表演：动作名”和“双击 START 结束表演”，安卓显示可直接点击的结束按钮。

取消时给一次短提示音，以及已有接口支持时的轻震动；不使用摔机红屏和强震动。显示“已结束，恢复站立”；在舞台等任务中补充“本段未完成，请重新表演”。取消不会扣成碰撞，也不会获得完整演出分。舞台此前完成的片段、路线和已保存节目保留。

教学入门增加 START 站立、踏步和中断一次表演的操作练习；安卓显示可完成同一教学目的的屏幕入口，不要求按没有响应的实体键。阻尼、零力矩、吊机与调试的教学说明保留。

## 5. 实现边界与代码落点

1. `drive-input.ts`：提取 START 双击识别，初值保持 330ms、集中可调；按下沿只计一次，必须释放再按，长按不算双击。舞蹈中收到第二击立即发独立 `cancelAction` 命令；第一击不发站立或踏步。播放期间不能沿用“按住修饰键就清空 START 首击”的规则，游客仍按着 RB 时也能双击结束。启动、失焦、断连、切设备 / 配置时清空待判定点击。
2. `drive-config.ts`：新增取消动作命令与必要的收势状态。取消逻辑使用实际播放状态，而非仅检查“动作表演模式”；行走模式下的握手、挥手也能停止。
3. `drive-state.ts`：集中处理取消、挂接与模式优先级。普通取消不调用 `finishGesture()`；单独记录中断，立即清理任务待完成候选。收势期间冻结新动作与移动，完成后要求松杆再接管。SELECT、LB、RB 组合不得泄漏 A 吊挂或 B 暂停。
4. `drive-rig.ts`：缓存取消瞬间的实际姿态，从当前角度、根节点高度 / 朝向平滑回到基准，不能简单清空动作令模型跳变。腾空特技继续到落地节点；调试预览返回悬吊基准。
5. `drive-main.ts`：接入手柄与触屏共用的取消命令；START 同 A 一样可激活 / 继续。暂停后继续按原有规则处理被中断片段，不能从暂停态误触踏步。
6. `drive-control-guide.ts`、操作台及任务说明：同步 START / SELECT 名称、当前状态提示和安卓替代卡。`drive-pad-layout.ts` 保留实测通道隔离，不为未确认按键补默认值。
7. 教学、接待、舞台状态机与动作音效：区分完成、暂停、主动取消；取消后停止该段音效、清除后续待播事件，不误报成功。不覆盖已经保存的 RB 四槽。

这轮不需要更换模型、增加物理引擎或加重渲染；手柄逻辑继续在现有输入轮询中计算，UI 仅在状态变化时刷新。

## 6. 实施后的验收重点

- 从站立开始，单击 START 进入行走；双击 START 进入踏步，再双击回站立；一组双击不能先触发单击。
- START 与 A 均可启动 / 继续；启动用的按键不顺带播动作，长按不重复触发，断连 / 切后台后不遗留首击。
- 在四种 RB 舞蹈及 SELECT 接待动作中双击 START，立即提示收势，平滑结束且不进入踏步；闲置时双击不触发舞蹈。
- 双击结束跳跃 / 后空翻时不在半空瞬间站直；挂接和调试中不会被 START 绕过互锁。调试预览结束后仍被吊带支撑。
- SELECT + B 不暂停，SELECT + A 不挂接；手柄按住 RB 后双击 START 仍能结束表演，模式组合键优先级不被破坏。
- 舞台取消只中断当前片段、不计完成分；重新完整演出可以继续通关，旧进度、键位与路线不丢失。
- 电脑标准和安卓原始通道模拟分别验证；安卓现场确认屏幕入口、RB 舞蹈、LB 模式与右杆转向。开发模拟不等于实体 START / SELECT 已读通。
- 展厅竖屏与已有横屏布局无滚动、无模型文字遮挡；原模式切换、起身、吊挂、速度和音效行为继续成立。

推荐先按本报告完成本地体验，再按用户后续指令决定发布。本文件仅为方案，不表示以上新行为已实现或已上线。
