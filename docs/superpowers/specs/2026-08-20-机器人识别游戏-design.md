# 机器人识别小游戏 — 设计文档

日期：2026-08-20
状态：已获用户批准

## 目的

做一个"看图识机型"的小游戏：显示一张机器人照片，玩家从 4 个选项中选出正确的品牌+型号。数据来自《机器人之家｜机型数据库 (2).xlsx》（182 台机型）。照片由用户后续提供，游戏按照片顺序出题。

## 已确定的需求

- 答题方式：**四选一选择题**（照片 + 4 个品牌型号选项）
- 干扰项策略：**全随机**——3 个错误选项从全部机型里随机抽取（不与正确答案重复）
- 布局：**A 居中卡片式**——照片大图居中，选项竖排下方
- 出题顺序：**按用户照片的顺序**（照片按编号 NO.xxx 命名放入 photos/ 目录）
- 游戏只包含**有照片的机型**；照片未到时用占位框，界面和逻辑先用文字+占位图可跑通

## 文件结构

```
robot-game/
├── index.html       ← 游戏界面 + 全部逻辑（单文件）
├── data/robots.js   ← 从 Excel 导出的机型数据（JS 数组）
├── photos/          ← 机器人照片，按编号命名（如 NO.001.jpg）
└── docs/superpowers/specs/  ← 本设计文档
```

## 数据字段（来自 Excel）

每台机型使用：`编号`、`品牌`、`型号`、`大分类`、`子分类`、`一句话特点`。
其余字段（详细介绍、应用场景等）本次不做。

## 界面结构（从上到下）

1. 顶部状态栏：第 X/N 题、得分、进度条
2. 照片区：大图（未加照片时显示灰色占位框）
3. 题干："这张是什么机器人？"
4. 4 个选项按钮（A/B/C/D，品牌 + 型号）
5. 答题反馈：对/错提示 + 正确答案 + 一句话特点（学习小卡片）
6. 结束页：总分（答对 X/N）+ 重新开始按钮

## 游戏逻辑

- 载入 `data/robots.js`，从 photos/ 里实际存在的图片文件名推断本轮题目（按文件名排序）
- 每题：取该机型的照片 → 生成 4 个选项（1 个正确 + 3 个随机干扰，打乱顺序）
- 点击选项：高亮所选，显示对错反馈与一句话特点，2 秒后进入下一题（或点"下一题"）
- 计分：答对 +10 分，答错 0 分
- 结束：显示总分、正确率、重新开始

## 技术要点

- 纯前端，无需构建工具：双击 index.html 即可玩（照片用相对路径 `<img src="photos/NO.001.jpg">`）
- 单文件 index.html 包含 HTML/CSS/JS，便于初学者通读
- 移动端友好：响应式布局，大按钮，适合手机/电脑
- 后续加照片：把照片按编号命名丢进 photos/ 即可，无需改代码

## 照片管理（手动匹配）页（2026-08-20 追加）

由于按文件顺序自动对应照片错得较多，改为游戏内提供"照片管理"页让用户手动逐张匹配：

- 开始页新增入口"⚙️ 照片管理（手动匹配）"
- 逐张显示 `photos/` 里的照片 + 文件名 + 当前匹配状态
- 搜索框输入品牌/型号/编号 → 点选正确的机器人，立即保存到浏览器 localStorage（键 `robotPhotoMap`：文件名 → 编号）
- 上一张/下一张循环浏览；进度"第 x/178 张 · 已匹配 n"
- 游戏出题顺序：优先用匹配表（`photoEntries()`），未匹配的退回按文件名推断；品牌内按编号从小到大

## 双模式（2026-08-20 追加，已批准）

游戏改为两种模式，开始页放两个入口按钮。

### 品牌选择页（2026-08-20 追加，已批准）

- 学习模式 / 考试模式都先经过品牌选择页，顶部标题区分当前模式
- 品牌按钮网格：按台数从多到少排序，只列**有照片**的品牌（64 个）
- 返回按钮回开始页；学习/考试页里也能随时"退出/返回"回到品牌选择页
- 每个品牌按钮：品牌名 + 有照片的台数

### 按品牌学习 / 考试（2026-08-20 追加，已批准）

- 学习模式（某品牌）：只翻看该品牌有照片的机型，顶部显示 `品牌 · 第 x/y 台`，顺序按照片清单
- 考试模式（某品牌）：只考该品牌有照片的机型，按照片顺序出题
- 错误选项：**同品牌优先**（`makeOptions(..., preferSameBrand=true)`）——优先用同品牌其他机型做干扰项；同品牌凑不满时自动用其他品牌补齐
- 开始页的"识图模式"改名为"考试模式"

### 学习模式（图鉴翻卡）

- 顶部：`第 X / 178 台` + 返回按钮
- 中间：照片大图
- 下方：品牌 + 型号（大字）、分类标签（大分类 · 子分类，小胶囊）、一句话特点（无则显示"（暂无一句话特点）"）
- 底部：`◀ 上一台` `▶ 下一台`，到头/到尾自动循环
- 顺序：和识图模式一样，严格按照片清单顺序（NO.372 → NO.001）
- 复用识图模式的照片渲染逻辑（onload 显示图片 / onerror 回退占位框）

### 识图模式

- 即原来的玩法：照片 + 4 选 1 答题，完全不变。
