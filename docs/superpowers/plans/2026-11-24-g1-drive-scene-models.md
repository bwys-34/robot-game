# G1 驾驶布景替换实现计划

**目标**　沿用原 G1 驾驶页面和训练地图，接入另一工作区制作的写实模型，并换掉迎宾和搬运人物。

- [x] 对照近景 GLB 与 `drive-config.ts` 的坐标，覆盖模型边界、搬运阶段和站位的回归验证。
- [x] 将 `drive-nearfield.glb` 装入原场景。替换地面、实验台、吊架静态结构和庭院布景，保留动态吊带、台阶标记、考场控制和加载失败时的原可视模型。
- [x] 裁剪已有的 `training-ground.glb`，仅接入建筑、花池与场外环境；沿用原训练路线和碰撞边界。
- [x] 从近景人物沿用脸、头发、眼睛和手的网格。迎宾采用站姿和回礼，搬运采用双人抬姿、脚步和台阶落脚，动画从现有任务进度取值。
- [x] 构建驾驶包，通过 318 项单测。开发 Edge 检查桌面、展厅竖屏和手机布局，核对迎宾回礼、搬运上台和下台及两套模型的失败回退。键盘跑通接待流程，模拟电脑手柄跑通驾驶考场和舞台挑战。

完成本地试玩后，用户于 2026-11-24 授权上线。见 [发布记录](../../releases/2026-11-24-g1-scene-models.md)。实体 Android 11 / Chrome 88 性能与真实手柄尚未验收。
