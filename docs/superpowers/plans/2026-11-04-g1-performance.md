# G1 动作编排实现计划

**目标：** 在现有 G1 页面增加十二个多关节动作、三个任务与自由编排，先提供本地试玩，等待用户确认后发布。

**架构：** 保留原发现、左腿示范和十三关摆姿训练。新增纯数据动作库、独立的编排与评分模型、时间驱动的连续姿态播放器和下方双列编辑面板。播放器使用现有 PoseChain 的关节安装轴、交互限位和支撑脚锚点，不引入新模型或物理引擎。

**技术栈：** TypeScript、现有 Three.js/esbuild、Node test、Playwright/Edge。
