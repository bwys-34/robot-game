# G1 简约音效、碰撞反馈与操作入门

目标：在现有驾驶页提供克制音效、撞墙倒地、逐步操作教学，本地试玩后再按用户指示发布。

沿用当前浅绿、金色强调与上下操作布局，1080×1800 安卓 Chrome 88 为主要目标。电脑与安卓手柄映射独立；文字放在模型外，不加入内部滚动。由当前会话顺序实施。

- [x] 新增 `drive-tutorial.ts`：前进、转向、站立、阻尼、起身、表演六个检查点。只根据运行中的实际位移、角度、机身和完成动作推进；暂停冻结，取消动作不算成功。教学文案随输入与手柄配置调整。
- [x] 调整 `drive-state.ts` / `drive-config.ts`：替换接待计分路径；碰墙/展台触发一次倒地，方向沿接触法线向内，推离碰撞面后恢复，重按起身和回中才可继续；保留模式切换与调试。
- [x] 调整 `drive-audio.ts`：运行时使用 minimal 配置，柔和短提示与低强度脚步，不播放持续鼓点、机械声；保留声音开关、后台释放和诊断原声。
