# G1 吊挂体验实现计划（首轮历史）

> **针对 agent 工作者：** 在当前会话内逐项执行；用户已经要求开始制作，完成本地预览后再由用户决定上线。不改动已有未提交的探索页文件。

**目标：** 驶入吊挂位、停稳、确认挂接，观察有支撑的阻尼和零力矩，再恢复站立并解挂离开。

**架构：** `DriveHoist` 管理定位停稳、挂接/解挂时间线和支撑有效性；`DriveState` 统一处理模式、移动互锁和无支撑倒地。`DriveHoistVisual` 用低面数门架、卷扬机和双吊带表达支撑；独立体验面板复用现有输入通道，只有该玩法中的无修饰 A 键执行上下文动作。

**技术栈：** TypeScript、Three.js、现有 Gamepad API、CSS，Chrome 88 构建目标。没有刚体/绳索物理引擎。
