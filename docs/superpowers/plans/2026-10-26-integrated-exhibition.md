# 大屏首页与机器人档案整合实现计划

**目标：** 大屏首页直接开始挑战（昵称可选），在同一站点内浏览 150 台机器人的完整档案，并随时进入识图游戏。

**架构：** 保留静态 HTML/CSS/JS 和黄黑研究所风格。共用现有 ROBOTS / PHOTO_LIST 稳定编号，新增本地档案内容和独立档案视图模块，由现有应用负责切换页面；不依赖远程档案网站运行。

**技术栈：** 原生 JavaScript、CSS Grid、Node test runner、Playwright / Edge。

### 1. 行为验收先行
- [x] 新增 `test/archive.test.js`：年份排序、编号及多字段查找、空结果、翻页边界、不修改原数据、150 条详情与照片映射。
- [x] 更新 `test/browser-compat.cjs`：空昵称开始成功、非法长昵称被拒绝；档案搜索→详情→返回保留列表状态；从详情开始挑战；原有完整答题与存档回归。
- [x] 运行 `node --test test/*.test.js` 和浏览器测试，记录新功能缺失导致的预期失败。

### 2. 本地档案数据与界面
- [x] `data/archive-details.js`：保存原公开档案中的简介、技术路线、应用及优缺点，以原稳定 id 关联现有机器人数据；记录来源。
- [x] `js/robot-archive.js`：纯筛选/排序/分页逻辑及独立视图工厂；复用完整本地照片；搜索和分页不产生外站请求。
- [x] 档案列表：每页 8 台，年份顺序，搜索和年份筛选，页码、清空、无结果状态；详情：完整照片、基本参数、4 个内容标签页；明显的返回和开始按钮。
- [x] 详情返回保留查询、筛选、页码与焦点；进入档案和详情更新本地路由，浏览器返回保持可用。

### 3. 大屏首页布局
- [x] `index.html`、`js/exhibition-app.js`：主区域直接展示开始挑战，昵称可选、留空使用“小小观察员”；档案入口切换内部视图，页头提供首页和档案导航，答题中跳转沿用退出确认。
- [x] `css/exhibition-home.css`：左侧海报标题/照片，右侧醒目的挑战面板和档案入口；竖屏依次展示简洁标题、操作区、照片。保留主题变量、清晰触控目标。
